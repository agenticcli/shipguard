# Support

- **How do I use ShipGuard?** Start with [Getting started](docs/getting-started.md), the [FAQ](docs/faq.md) and [CI and agent setup](docs/ci-setup.md). Full docs: [agenticcli.dev/shipguard/docs](https://agenticcli.dev/shipguard/docs).
- **Questions and ideas**: use [GitHub Discussions](https://github.com/agenticcli/shipguard/discussions).
- **Bug or false positive**: open an [issue](https://github.com/agenticcli/shipguard/issues/new/choose). Include `shipguard --version`, the command you ran and the smallest file that shows the problem. Do not paste real secrets.
- **Security problem**: do not open a public issue. Follow [SECURITY.md](SECURITY.md).
- **Billing and account help**: support@agenticcli.dev
- **General questions and press**: contact@agenticcli.dev

# Contributing

Thanks for your interest in ShipGuard. The source is public under the [Elastic License 2.0](LICENSE) so you can read exactly what runs in your repo.

- **Bug or false positive**: open an [issue](https://github.com/agenticcli/shipguard/issues) with the ShipGuard version (`shipguard --version`), the command you ran and the smallest file that shows the problem. Do not paste real secrets.
- **Security problem**: do not open an issue. Follow [SECURITY.md](SECURITY.md).
- **Code change**: open an issue first so we can agree on the change, then send a pull request with a test. Run `pnpm install` and `pnpm test` before you push.
- **Help with using ShipGuard**: see the [FAQ](docs/faq.md) or the [contact page](https://agenticcli.dev/contact).

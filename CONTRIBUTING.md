# Contributing

Thanks for your interest in ShipGuard. The source is public under the [Apache License 2.0](LICENSE) so you can read exactly what runs in your repo.

- **Bug or false positive**: open an [issue](https://github.com/agenticcli/shipguard/issues/new/choose) with the ShipGuard version (`shipguard --version`), the command you ran and the smallest file that shows the problem. Do not paste real secrets.
- **Security problem**: do not open an issue. Follow [SECURITY.md](SECURITY.md).
- **Code change**: open an issue first so we can agree on the change, then send a pull request with a test. Run `pnpm install` and `pnpm test` before you push.
- **Help with using ShipGuard**: see the [FAQ](docs/faq.md) or the [contact page](https://agenticcli.dev/contact).

- **Pro rules never enter this repo.** Do not add, paste or propose Pro rulebook content here. This repository holds the CLI and the free rules only.

## License of contributions and sign-off

By contributing you agree your contribution is licensed under the [Apache License 2.0](LICENSE), the same as the project. We use the [Developer Certificate of Origin 1.1](https://developercertificate.org): add a `Signed-off-by: Your Name <you@example.com>` line to every commit with `git commit -s`. That line certifies that you wrote the change or have the right to submit it under the project license. Sign-off is text-only for now: it is not checked by a workflow.

Please be kind: this project follows the [Code of Conduct](CODE_OF_CONDUCT.md). For all the ways to get help, see [SUPPORT.md](SUPPORT.md).
